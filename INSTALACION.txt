ABRIR DIRECTAMENTE EN EL ORDENADOR

1. Descomprime el ZIP.
2. Abre el archivo index.html de la carpeta viva-studio con doble clic.
3. El editor, sus controles y el codificador MP3 están integrados en ese HTML:
   ya no dependen de la carga de módulos JavaScript desde archivos separados.
4. Importa tus audios, edítalos y exporta la mezcla.
5. Para el micrófono y la selección de salida, el navegador necesita los permisos
   y las APIs correspondientes. Si no los habilita al abrir un archivo local,
   utiliza el editor en tu hosting con HTTPS.

DETECCIÓN AUTOMÁTICA DE ENTRADAS Y SALIDAS

La barra Entrada / Salida consulta automáticamente los dispositivos disponibles
al abrir el editor y actualiza las listas cuando conectas o desconectas hardware.
Por defecto, se utilizan la entrada y la salida que tenga elegidas tu sistema.
El botón Detectar solicita permiso al navegador para mostrar los nombres de los
micrófonos, interfaces de audio, auriculares y altavoces disponibles.
Esta comprobación libera el micrófono al terminar; no inicia una grabación.

El selector Entrada elige el micrófono que se usará al grabar.
El selector Salida cambia el destino de la reproducción cuando el navegador
permite elegir dispositivos. Si no ofrece esa API, la reproducción sigue usando
la salida predeterminada: puedes cambiarla desde los ajustes de sonido del equipo.
El botón Permitir salida aparece cuando el navegador ofrece un diálogo de selección.
Al desconectar la salida seleccionada, el editor vuelve a la salida del sistema.

INSTALACIÓN EN HOSTING

1. Descomprime el ZIP. Encontrarás una carpeta llamada viva-studio.
2. En el administrador de archivos del hosting o por FTP, crea una carpeta
   dentro del directorio público de tu dominio. Por ejemplo: public_html/estudio/.
3. Sube DENTRO de esa carpeta los archivos y subcarpetas que hay en viva-studio,
   manteniendo sus nombres. index.html debe quedar dentro de estudio/.
4. Activa el certificado HTTPS de tu dominio en el panel de tu hosting.
5. Abre https://tudominio.es/estudio/ en el navegador.

También puedes subir el contenido directamente a la raíz de un subdominio.
El editor funciona tanto en la raíz del dominio como dentro de una subcarpeta.
No requiere instalar PHP, bases de datos ni Node.js en el hosting.
El archivo index.html es autónomo. Los módulos editables, el código fuente de los
codificadores, las pruebas y sus licencias también están incluidos en el paquete.

WORDPRESS

Puedes instalarlo en una carpeta aparte, por ejemplo /estudio/, dentro del mismo
hosting que tu WordPress. Añade un enlace a esa dirección desde tu menú.
Este paquete es una aplicación web independiente; no es un plugin de WordPress.
No pegues el contenido de index.html en el editor de una entrada: sube los archivos.

CÓMO USARLO

Al abrirlo encontrarás un proyecto en blanco con Pista 1, Pista 2 y Pista 3
vacías. Antes de entrar, elige Proyecto en blanco, Importar audio, Explorar una
demo o Recuperar sesión anterior. Hasta elegir, todos los controles del editor,
el mezclador, las pistas, el arrastre y los atajos están desactivados. Importar y
recuperar habilitan el editor solo después de cargar correctamente el audio o
la sesión; cancelar el selector o una carga fallida mantiene la pantalla inicial.
Ninguna pista tiene Rec activado y no se abre el micrófono al entrar. Puedes
empezar en blanco, importar un audio o explorar la demo de sonidos sintetizados.
La demo se carga únicamente al pulsar su botón. Si existe una sesión anterior
autoguardada en este navegador, puedes recuperarla con el botón correspondiente.
Abrir el editor no reemplaza esa sesión por el proyecto vacío.

- Importar audio: selecciona uno o varios archivos o arrástralos a las pistas.
- Probar micro: selecciona una Entrada y pulsa Probar micro. Habla y comprueba
  el medidor de entrada y el aviso Señal recibida. Finalizar prueba libera el
  micrófono; la prueba no graba audio ni crea clips. Si cambias de entrada durante
  la prueba, se comprueba el nuevo dispositivo.
- Vúmetro de entrada: activa REC en la pista de destino. Se abre el micrófono y
  aparece un medidor junto a M, S y REC que responde en tiempo real, incluso antes
  de grabar. Verde indica entrada, amarillo un nivel alto y rojo cercanía a 0 dBFS.
  Al pasar el ratón por el medidor se muestra el nivel en dBFS y el micrófono.
  Este medidor lee la entrada, independientemente del silencio/solo de las pistas.
  Desactivar REC o pulsar Detener entrada cierra el micrófono. Cambiar de pista
  mueve el medidor a la nueva pista sin abrir otra entrada. Cambiar Entrada cambia
  el micrófono que se comprueba. No se crean clips durante esta comprobación.
- Grabar: selecciona REC, autoriza el micrófono cuando lo solicite el navegador,
  coloca el cursor y pulsa el botón rojo. Para finalizar,
  pulsa otra vez el botón rojo o el botón Detener. La onda de entrada se dibuja
  en directo en la pista mientras grabas; no necesitas esperar a finalizar.
  Al terminar, el vúmetro sigue disponible mientras REC esté activado. Al crear
  un proyecto nuevo, abrir otro o cargar la demo, se cierra la entrada. Los
  proyectos abiertos requieren activar REC de nuevo para acceder al micrófono.
- Editar: arrastra los clips para moverlos y sus extremos para recortarlos.
  El recorte se ve y se escucha durante el arrastre: onda, puntos y duración
  se actualizan sin esperar a soltar el ratón.
  Coloca el cursor dentro del clip y pulsa S para dividirlo.
- Altura de pistas: el control Altura general cambia el grosor de todas las
  pistas. Arrastra el borde inferior de una pista para ajustar solo esa pista.
  La onda y la línea de volumen se adaptan a su altura; el tamaño queda guardado
  en el proyecto. Con el tirador enfocado, las flechas arriba/abajo también sirven.
- Ordenar pistas: usa las flechas visibles ↑ / ↓ junto al nombre de cada pista
  para subirla o bajarla una posición. La primera no puede subir y la última no
  puede bajar; esas flechas se muestran desactivadas. También puedes arrastrar
  el asa de puntos junto al número de la pista. Una línea
  indica si la colocarás encima o debajo de la pista de destino. El mezclador
  refleja el mismo orden. También puedes enfocar el asa y usar Alt+flecha arriba
  o Alt+flecha abajo. Se conservan los audios y los ajustes de cada pista.
- Color de pista: pulsa el cuadrado de color junto al nombre de la pista y elige
  cualquier color. Sus bloques, ondas y canal del mezclador se actualizan juntos.
  Los clips nuevos o movidos a esa pista adoptan su color. El ajuste se conserva
  al guardar/abrir el proyecto y se puede deshacer. Silencio/Solo muestran el gris
  correspondiente sin perder el color elegido; al desactivarlos vuelve ese color.
- Línea de volumen: cada bloque empieza con una línea blanca punteada en el centro
  de la forma de onda y dos puntos, uno al principio y otro al final. El centro
  equivale a 0 dB / 100 %. Arrastra la línea arriba para subir el volumen o abajo
  para bajarlo. El cambio se escucha durante la reproducción sin reiniciar el audio.
  Arrastra los puntos para ajustar tramos y añade puntos con el botón derecho.
  Al pasar el ratón, el punto se ilumina, crece ligeramente y muestra su nivel.
- Curvas de volumen: al pasar el puntero por la línea entre dos puntos blancos
  aparece un punto amarillo más pequeño en el centro de ese tramo. Arrástralo
  verticalmente para elegir una transición más suave o más pronunciada. Los
  extremos mantienen su tiempo y su volumen; el cambio se dibuja y se escucha
  durante el arrastre. Un doble clic sobre el amarillo vuelve a la línea recta.
  Con el punto amarillo enfocado también puedes usar las flechas arriba/abajo.
  Si los extremos tienen el mismo nivel, el tramo permanece plano; la forma se
  aprecia cuando sus niveles son diferentes. Las curvas se conservan al guardar,
  duplicar, dividir, recortar o copiar fragmentos, y se aplican al MP3/WAV.
  Al crear un punto blanco nuevo, la curva anterior conserva su sonido.
- Atajo P: coloca el puntero sobre el bloque de audio de cualquier pista y pulsa
  P para crear un punto de volumen en esa posición horizontal. Se abre de inmediato
  Ajustar volumen, aplicado a ese punto, para fijar, subir o bajar su nivel en dB
  o %. Cancelar la ventana conserva el punto con su nivel anterior. No hace falta
  seleccionarlo previamente. Se respeta el ajuste temporal y el nivel actual de
  la línea para no cambiar de golpe el volumen. Si ya existe un punto allí, se
  selecciona sin duplicarlo. Puedes deshacer su creación y se guarda con el
  proyecto. P no actúa al escribir en campos, durante la grabación o carga, en
  la pantalla inicial ni al combinarla con Ctrl/Cmd/Alt. Funciona mientras
  escuchas la mezcla, sin detener la reproducción.
- Cantidades de volumen: clic derecho -> Ajustar volumen en dB / %. Puedes fijar
  un nivel, aumentar o reducir el volumen escribiendo tu propia cantidad. Se aplica
  al punto pulsado o al bloque completo si haces clic fuera de un punto.
  0 dB / 100 % es el nivel original; 50 % equivale aproximadamente a -6 dB.
  Aumentar un 25 % multiplica el nivel actual por 1,25; reducirlo un 25 % lo
  multiplica por 0,75. Aumentar/reducir en dB suma/resta esa cantidad al nivel actual.
  Confirma el ajuste con Aceptar o pulsando Enter: ambos aplican la misma
  decisión y cierran la ventana si el valor es válido. Cancelar y el cierre
  conservan el nivel anterior. Los valores inválidos mantienen la ventana abierta.
  No hay una lista de valores obligatorios. En Propiedades también puedes cambiar
  la unidad dB/% y escribir el nivel del punto seleccionado o de todo el bloque.
  Los cambios se conservan al cortar, duplicar, guardar y exportar a MP3/WAV.
- Unir: haz clic en los dos bloques que quieres unir en una misma pista y pulsa W.
  No hace falta mantener Ctrl al seleccionarlos. Verás ambos bloques resaltados.
  Puedes seleccionar más bloques, incluso de otras pistas. Para unir con W,
  deben estar seleccionados exactamente dos de la misma pista. Hacer clic en
  un espacio vacío quita la selección. Solo se unen esos dos bloques. Se mantienen
  su posición temporal, sus cambios de volumen, recortes y fundidos; los huecos
  intermedios se conservan como silencio. Deshacer restaura los dos originales.
- Mover en grupo: haz clic en los bloques que quieras seleccionar, también en
  pistas distintas. Arrastra uno de los bloques por su cabecera o por la onda
  fuera de la línea de volumen. Se moverán todos a la vez y mantendrán sus
  distancias temporales. Puedes desplazarlos a otras pistas sin alterar la
  separación entre ellas. El grupo se detiene al llegar al inicio de la sesión
  o a la primera/última pista, para no perder ninguno de sus bloques.
  La selección se mantiene tras moverlos; un clic en un espacio vacío la quita.
  Deshacer restaura el movimiento completo con una sola operación.
- Copiar/cortar/pegar: clic derecho sobre un bloque completo o un fragmento
  seleccionado y elige la operación. Para pegar, pulsa el botón derecho en la
  posición de destino de cualquier pista. Ctrl+C, Ctrl+X y Ctrl+V también funcionan;
  Ctrl+V pega en la pista activa y en la posición del cursor temporal.
- Progreso: durante la carga y preparación del audio se muestra una barra visible.
  La lectura indica el porcentaje cuando el navegador puede medirlo; la
  descodificación muestra actividad mientras se procesa. Al exportar, la mezcla
  muestra actividad y la codificación MP3 indica su progreso hasta completar.
- Menú con botón derecho: abrirlo sobre un audio o una pista mantiene la
  reproducción en marcha, incluida la escucha de un segmento. Puedes consultar
  las opciones y ajustar los puntos o cantidades de volumen mientras escuchas.
- Banderitas de anotación: haz clic derecho sobre la regla de minutos y segundos
  para crear una bandera blanca en esa posición y abrir su nota. La ventana
  muestra el tiempo de la banderita y permite escribir o leer anotaciones.
  Se conserva lo escrito mientras editas, al guardar la anotación y al cerrar
  la ventana. Haz clic en una banderita para volver a abrirla; el clic derecho
  sobre una existente también la abre sin duplicarla. Eliminar banderita permite
  quitarla y Deshacer la recupera. Las notas se guardan en el autoguardado y en
  el archivo .vivastudio, para recuperarlas en otra sesión. Crear/abrir/editar
  una nota no detiene la reproducción ni cambia la posición del cursor.
  Los proyectos anteriores siguen abriéndose aunque no incluyan anotaciones.
- Atajo B: pulsa B para crear una banderita en la posición de la línea vertical
  del cursor, tanto durante la reproducción como con el audio detenido o en
  pausa. También funciona mientras grabas. Puedes situar el cursor en cualquier
  momento de la línea de tiempo y marcarlo sin iniciar la reproducción.
  La posición no se redondea a la rejilla temporal y el atajo no detiene ni
  inicia el sonido. La ventana de notas no se abre automáticamente: puedes
  seguir marcando instantes y después hacer clic en cada banderita para escribir.
  B no genera marcas al escribir en campos, con Ctrl/Cmd/Alt, si mantienes la
  tecla pulsada ni en la pantalla inicial antes de elegir un proyecto.
- Marcadores de corte: el menú de clic derecho ofrece Añadir marcador de corte
  para definir segmentos. Añade dos marcadores y selecciona el tramo entre ellos.
  También puedes marcar un inicio y un final desde el menú.
- Segmentos: con el tramo seleccionado puedes escucharlo, copiarlo, cortarlo,
  duplicarlo, silenciarlo, eliminarlo, conservarlo o exportarlo en MP3/WAV.
  Para pegar, haz clic derecho en la posición de destino de una pista.
  Separar segmento crea un clip independiente para ajustar volumen y fundidos.
  El resto del audio conserva su posición. Escape quita la selección.
  Deshacer y Rehacer permiten revertir las operaciones y el orden de pistas.
- Balance por pista: debajo de la ganancia encontrarás un deslizador L / R.
  El centro mantiene el sonido equilibrado; a la izquierda se desplaza hacia L
  y a la derecha hacia R. El indicador muestra Centro o el porcentaje aplicado.
  Está sincronizado con el panorama del mezclador, se escucha al reproducir y
  se aplica al exportar. Se guarda en el proyecto y permite Deshacer/Rehacer.
  En pistas muy finas puedes desplazar el panel de controles para llegar a todos
  los ajustes sin cambiar su altura.
- Mezclar: ajusta volumen, panorama, ecualizador, compresor y fundidos.
  M silencia una pista y la muestra gris con su onda en gris claro.
  S escucha una sola pista: la pista con S activa conserva su color y el resto
  queda gris con la onda en blanco pálido. La S activa queda resaltada. Al salir de Solo vuelven los colores originales,
  salvo las pistas que sigan silenciadas.
- Play por bloque: el pequeño botón de play de la cabecera escucha únicamente
  ese bloque, desde su inicio hasta su final, respetando su recorte, puntos de
  volumen, fundidos, ganancia, balance y efectos de pista. El resto de bloques
  queda fuera de esta escucha, sin modificar los botones M/S ni la selección.
  Vuelve a pulsarlo para detenerla, o pulsa el de otro bloque para cambiar.
  El botón se ilumina mientras suena y se restablece al llegar al final.
- Desplazamiento horizontal: la barra inferior empieza en el área de audio,
  después del panel de controles de las pistas. Está sincronizada con la línea
  de tiempo al moverla, cambiar el zoom o grabar. Los controles permanecen fijos.
  Con el foco en la barra puedes usar las flechas, Inicio/Fin y Re Pág/Av Pág.
- Zoom con la rueda: coloca el puntero sobre la regla de tiempo o el área de
  audio de las pistas. Gira la rueda hacia arriba para acercar y hacia abajo
  para alejar, sin pulsar ninguna tecla. El instante bajo el puntero permanece
  en su lugar mientras lo permitan los límites de desplazamiento.
  La rueda no cambia la posición temporal del cursor ni detiene el sonido.
  El deslizador y los botones de zoom siguen disponibles. Sobre los controles
  de una pista la rueda permite desplazarte normalmente; Mayús + rueda conserva
  el desplazamiento, y Ctrl/Cmd + rueda conserva el zoom del navegador.
  El zoom funciona con el audio detenido, reproduciéndose o grabándose y queda
  desactivado en la pantalla inicial hasta que elijas cómo comenzar.
- Guardar proyecto: descarga un archivo .vivastudio que incluye todos sus audios.
- Abrir: importa de nuevo un proyecto .vivastudio para continuar trabajando.
- Exportar: descarga la mezcla en MP3 de 128, 192, 256 o 320 kbps, o en WAV.
- Región: arrastra sobre la regla temporal para seleccionar un fragmento,
  reproducirlo en bucle o exportarlo por separado.

GUARDADO Y PRIVACIDAD

Los audios se procesan en el navegador del usuario, sin enviarse al servidor.
El autoguardado se conserva en ese navegador y en esa dirección web mediante
IndexedDB. No se comparte entre equipos ni entre navegadores. Puede perderse
si se borran los datos del navegador. Descarga tu proyecto para conservarlo.

El hosting sirve los archivos de la aplicación. Este paquete no incluye cuentas
de usuario, almacenamiento de proyectos en la nube, MIDI ni plugins VST.
La memoria disponible del navegador condiciona la duración y el número de audios
que puedes editar. Los formatos de importación dependen del navegador.

MICRÓFONO Y COMPATIBILIDAD

En el hosting, la grabación necesita HTTPS, permiso de micrófono y un navegador
con AudioWorklet o MediaRecorder.
La grabación utiliza directamente el flujo del micrófono mediante MediaRecorder,
tanto en archivos locales como en el hosting. La captura no depende del volumen,
los botones M/S, la reproducción de la mezcla ni la carga de módulos AudioWorklet.
Cuando el navegador no ofrece captura nativa compatible, en HTTPS puede usarse
AudioWorklet como alternativa. El motor de entrada se reactiva después del
permiso y el medidor comprueba los canales por separado.
Al finalizar, la toma se convierte para editarla y exportarla a MP3. Si falla esa
conversión, se descarga una copia del audio original para conservar la grabación.
El aviso de la entrada muestra el nombre real del micrófono, si está silenciado,
si recibe señal y si la toma guardada está en silencio.
Si no entra señal, pulsa Probar micro, elige explícitamente tu micrófono en Entrada
y comprueba su volumen y su botón de silencio en Windows/macOS. El navegador no
puede activar una entrada silenciada por el sistema ni sustituir sus permisos.
Si estás usando auriculares con micrófono, elige la entrada correcta en el selector.
Si grabas sobre música, usa auriculares para que no vuelva a entrar por el micrófono.
Si cambias de dispositivo o desconectas el micrófono, revisa la entrada seleccionada.
La aplicación no activa la escucha directa de la entrada para evitar acoples.

Si lo incrustas en un iframe, la página que contiene el iframe debe permitir
el micrófono. Ejemplo: <iframe src="/estudio/" allow="microphone" ...></iframe>.
Las políticas de permisos del hosting también deben permitirlo.
Para empezar, es más sencillo abrir directamente la dirección /estudio/.

SI LA PÁGINA NO CARGA

- Comprueba que el index.html que has abierto es el de la versión 1.11.0.
- Si reemplazas una versión del hosting, vacía su caché y vuelve a cargar la página.
- Una política de seguridad personalizada del hosting debe permitir los scripts
  integrados y los workers blob que usa el editor.
- Vacía la caché si has reemplazado una versión anterior.
- Ahora sí puedes abrir index.html con doble clic para utilizar los controles,
  importar, editar y exportar. La grabación depende de los permisos del navegador.
- La configuración .htaccess incluida ayuda a Apache a servir el archivo inicial
  y el tipo MIME de JavaScript. Nginx y otros servidores necesitan su propia
  configuración; normalmente un hosting estático ya sirve estos tipos correctamente.

CÓDIGO Y LICENCIAS

Se incluye todo el código editable de la aplicación. El HTML ya está preparado
y no necesita compilación para usarlo. Después de editar los módulos fuente,
ejecuta npm run build para regenerar index.html. index.template.html es la plantilla
para modificar la estructura; build-standalone.mjs genera el HTML autónomo.
La codificación MP3 utiliza lamejs / LAME, distribuido por separado junto a sus
licencias y al archivo fuente lame.all.js. Conserva estos avisos al redistribuirlo.
Más información: https://github.com/zhuker/lamejs y https://lame.sourceforge.io/.

La carpeta tests contiene las pruebas automatizadas. No hace falta subirla para
usar el editor. Para ejecutarlas en desarrollo necesitas Node.js y, para las
comprobaciones de MP3, ffmpeg y ffprobe; ejecuta npm test en esta carpeta.
